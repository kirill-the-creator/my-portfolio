
#  Личный сайт-портфолио | Кирилл

Добро пожаловать! Это мой первый мини-проект, где я пробую себя в роли frontend-разработчика.  
Проект содержит две страницы:

- **Главная (`html.html`)** — сайт-визитка моего кота Скади 
- **О хозяине (`index.html`)** — моя страница с личной информацией и мини-приложениями

---

##  Технологии

- HTML5 + CSS3
- JavaScript (ES6+)
- Flexbox + Grid
- Адаптивная вёрстка
- DOM-манипуляции
- Простая смена темы (тёмная/светлая)

---

## ️ Функциональность

-  **To-Do** — добавление задач
-  **Аудиоплеер** — проигрывание локального mp3-файла
-  **Калькулятор возраста кота** — переводит возраст человека в кошачьи годы
-  **Тёмная тема** — переключатель доступен в шапке
-  Адаптивный дизайн — смотрится хорошо на телефонах и десктопах
